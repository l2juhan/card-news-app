# 피드백 루프 기록

> 역할: `harness-feedback` 스킬과 `/gc` 커맨드가 자동으로 기록하는 보강 이력.
> 사람이 수동으로 추가해도 됨. 신규 항목은 표 상단에 추가(최신순).

## 보강 레벨 정의

| Level | 설명 |
|-------|------|
| **1** | 문서 보강 (소프트 강제). docs/FRONTEND.md / docs/DESIGN.md에 규칙 추가 |
| **2** | 린트 규칙 추가. ESLint 규칙으로 변환 → Hook이 자동 잡음 |
| **2.5** | 린트 교정 지시(remediation message) 업데이트. 에이전트가 같은 에러를 잘못 고치는 패턴 발견 시 |
| **3** | 구조적 테스트 추가. `__tests__/structural/`에 패턴 검증 테스트 |

## 사용 안내

- `harness-feedback` 트리거: "같은 실수가 반복돼", "하네스 보강해줘", "규칙 추가해줘", "피드백 루프"
- 자동 트리거: QA가 같은 패턴 2회+ 감지 시, Hook이 같은 규칙 3회+ 자동 교정 시
- `/gc` 실행 시 발견된 드리프트도 이 표에 기록됨
